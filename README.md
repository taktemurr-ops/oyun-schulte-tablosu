# Sayı Tablosu · Number Table

Sayıları sırayla, en hızlı şekilde bul!

Karışık dizilmiş sayılara 1’den başlayarak sırayla dokun. Yanlış dokunuşlar sayılır; süre bitmeden bütün tabloyu bitir. Tablo zorlukla 3×3’ten 6×6’ya büyür.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Zihin Antrenmanı merkez uygulamasının oyunu; ortak motor: [zihin-motoru](https://github.com/taktemurr-ops/zihin-motoru).
